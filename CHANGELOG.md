- (EN) Settled both open capacity questions. A full event buffer now folds a repeating cycle into one round plus a count and the time of the last copy, rather than discarding events: the polling-heavy catalog scenario went from four lost events to none, and the run's conclusion — the lines a test asserts on — now survives. A run that fits is never touched, so existing pinned traces do not move; when nothing repeats, the last slot becomes a truncation notice so a trace never ends without explanation. Wake slots stay at eight, because a slot is spent per distinct moment rather than per device. The cost is 80 -> 96 bytes per event record (5,120 -> 6,144 bytes at the 64-slot default).

- (EN) Added a second folding tier for the one shape the first could not handle: a burst whose every value differs.
